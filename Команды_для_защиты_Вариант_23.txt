ВАРИАНТ №23 — КОМАНДЫ ДЛЯ ПРОВЕРКИ И ЗАЩИТЫ

Терминал: MSYS2 UCRT64
Папка проекта:
/c/Users/STRIX/Desktop/учеба/конфУправление/пр3/proga

1. Перейти в папку проекта:
cd "/c/Users/STRIX/Desktop/учеба/конфУправление/пр3/proga"

2. Проверить инструменты:
g++ --version
cmake --version
ninja --version
curl --version

3. Собрать проект, запустить тесты и основной пример:
bash run_windows.sh

4. Три тестовых сценария:
./build/visualizer.exe examples/config_A.toml
cp graph.svg graph_A.svg
cp graph.puml graph_A.puml

./build/visualizer.exe examples/config_X.toml
cp graph.svg graph_X.svg
cp graph.puml graph_X.puml

./build/visualizer.exe examples/config_P.toml
cp graph.svg graph_P.svg
cp graph.puml graph_P.puml

5. Повторный запуск автоматических тестов:
ctest --test-dir build --output-on-failure

6. Создать конфигурацию для реального Alpine APKINDEX:
cat > config_real.toml <<'TOML'
package = "curl"
repository = "https://dl-cdn.alpinelinux.org/alpine/v3.24/main/x86_64/APKINDEX.tar.gz"
test_mode = false
ascii_tree = true
max_depth = 2
TOML

7. Запустить анализ реального репозитория Alpine:
bash run_windows.sh config_real.toml

8. Открыть папку с результатами в Проводнике Windows:
explorer.exe .

Файлы, которые нужно показать преподавателю:
- config.toml — основная конфигурация;
- test_repo.txt — учебный граф;
- src/config.cpp — чтение и проверка TOML;
- src/repository.cpp — чтение тестового файла и APKINDEX;
- src/graph.cpp — DFS, обратные зависимости, PlantUML, SVG, ASCII;
- src/main.cpp — порядок работы приложения;
- tests/test_main.cpp — автоматические тесты;
- graph_A.svg, graph_X.svg, graph_P.svg — три тестовых изображения;
- graph.puml — текст PlantUML;
- CMakeLists.txt, run_windows.sh — сборка и запуск.

Примечания:
- Сборка и автоматические тесты уже успешно выполнены в MSYS2 UCRT64.
- Тестовые сценарии A, X, P уже запускались.
- Реальный режим считается проверенным только после успешного запуска команды из пункта 7 на компьютере с доступом к Интернету.
- Если русские буквы отображаются некорректно в окне Windows Terminal, попробуйте перед запуском программы выполнить: chcp.com 65001


9. Проверка Git перед отправкой преподавателю:
git status
git log --oneline

10. Настроить автора новых коммитов (подставить свои данные):
git config user.name "Имя Фамилия"
git config user.email "ВАШ_EMAIL"

11. После создания пустого репозитория на GitHub добавить адрес (подставить свой URL):
git remote add origin https://github.com/ВАШ_ЛОГИН/variant23-dependency-visualizer.git
git push -u origin master

Если origin уже настроен, проверить адрес командой git remote -v. Подробная
инструкция находится в GIT_SETUP.md.
