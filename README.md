# Визуализатор зависимостей Alpine APK — вариант №23

Проект разрабатывается по пяти этапам практической работы. На первом этапе
создано CLI-приложение с настройками из `config.toml`.

## Запуск

```bash
./run.sh
```

Можно передать путь к другому TOML-файлу:

```bash
./run.sh examples/config_A.toml
```
