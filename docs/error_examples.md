# Проверка ошибок конфигурации

Ниже перечислены ошибки, которые проверяются загрузчиком TOML и тестами.

| Параметр | Некорректный пример | Ожидаемая реакция |
|---|---|---|
| `package` | `package = "../bad"` | Недопустимое имя APK-пакета |
| `repository` в тестовом режиме | `repository = "missing.txt"` | Сообщение, что файл не найден |
| `repository` в реальном режиме | `repository = "file:///tmp/APKINDEX.tar.gz"` | Требуется URL http или https |
| `test_mode` | `test_mode = maybe` | Допустимы только true и false |
| `ascii_tree` | `ascii_tree = yes` | Допустимы только true и false |
| `max_depth` | `max_depth = -1` или `max_depth = 101` | Глубина должна быть от 0 до 100 |
| `max_depth` | `max_depth = two` | Требуется целое число |

Также проверяются отсутствие обязательных ключей, повторяющиеся и неизвестные
ключи, некорректный формат строк и ошибки структуры тестового репозитория.
Автоматические проверки запускаются командой `ctest --test-dir build`.
