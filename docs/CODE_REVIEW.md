# Проверка структуры и простоты проекта

## Как устроен код

В проекте четыре основных исходных файла и один общий заголовок:

- `src/main.cpp` — запускает программу и вызывает остальные функции;
- `src/config.cpp` — читает пять параметров из TOML и проверяет ошибки;
- `src/repository.cpp` — читает учебный файл или загружает и разбирает APKINDEX;
- `src/graph.cpp` — строит прямой и обратный граф, печатает дерево и создаёт файлы PlantUML и SVG;
- `include/depviz.hpp` — содержит общие структуры и объявления функций.

Для хранения графа используются стандартные контейнеры C++: `map` и `vector`.
Для обхода DFS используется собственный стек на основе `vector`. Рекурсивного
обхода графа нет. Сторонние библиотеки для получения зависимостей не применяются.

## Проверенные случаи

Автоматические тесты проверяют чтение конфигурации, ошибки параметров,
разбор записей APKINDEX, прямые зависимости, ограничение глубины, короткий
путь к общей вершине, цикл и обратные зависимости.

Дополнительно проверены три учебных сценария: ветвящийся граф A, повторная
зависимость X и цикл P -> Q -> R -> P. Сборка и тесты выполняются через CMake
и CTest.

## Ограничения реализации

1. TOML-загрузчик поддерживает простой набор конструкций, используемый в
   `config.toml`: пары ключ-значение, строки в двойных кавычках, логические
   значения, целые числа и комментарии. Полная спецификация TOML не реализуется.
2. Обрабатывается старый текстовый индекс `APKINDEX.tar.gz` (v2). Новый
   бинарный формат `Packages.adb` не поддерживается.
3. Ограничения версий зависимостей удаляются из токенов. Полный алгоритм
   разрешения версий и конфликтов пакетов не реализуется.
4. Виртуальные зависимости `provides` сопоставляются с выбранным пакетом-
   провайдером по приоритету `k`; это упрощённая модель.
5. В реальном режиме для загрузки и распаковки архива используются системные
   команды `curl` и `tar`. Содержимое APKINDEX разбирается собственным кодом.

Эти ограничения описаны явно, чтобы не выдавать учебный анализ графа за полный
механизм установки и разрешения зависимостей Alpine APK.
